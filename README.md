# Cupcake Delights

Restaurant and Bar Order Management System

## Features
- Table QR codes for instant ordering
- Separate Food & Bar menus
- Staff dashboards (Waiter/Bartender)
- Admin panel with analytics
- Telegram notifications
- Real-time order management

## Roles
- **Admin**: Full access - menu, staff, analytics, settings
- **Waiter**: View and manage food orders
- **Bartender**: View and manage drink orders

## Default Login
- Admin: admin / admin
- Waiter: waiter / admin
- Bartender: bartender / admin
